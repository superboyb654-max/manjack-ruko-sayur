# 🥬 Manjack Ruko Sayur - Timbang Per Ons

POS Ruko Sayur Tanjung Selor - Bulungan
Rumus: 1kg = 10 ons, 1 ons = 100 gram
Harga per ons = Harga per kg / 10

## Fitur:
- 24 sayur + tahu tempe
- Timbangan manual per ons (ketik 7 = 7 ons = 0.7kg = 700gr)
- Quick button 1, 2, 2.5, 5 (½kg), 10 (1kg), 15, 20 ons
- Keranjang, total, bayar, struk
- Offline 100%

## Deploy:
1. Settings > Pages > Branch main > Save
2. Link jadi: https://username.github.io/manjack-ruko-sayur/
3. Buka di Chrome > Titik 3 > Tambahkan ke Layar Utama = jadi APK!

## Auto APK:
Push ke main = Actions auto build APK debug.
Download di tab Actions > Build APK > Artifacts.
